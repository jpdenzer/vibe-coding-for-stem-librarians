# Vibe Coding for STEM Librarians

### 👉 **Read the guide here: [jpdenzer.github.io/vibe-coding-for-stem-librarians](https://jpdenzer.github.io/vibe-coding-for-stem-librarians/)**

This is the companion resource for the talk **"Vibe Coding for STEM Librarians: What It Really Is and How It Can Help You,"** given at the Upstate New York Science Librarians (NYSCILIB) meeting on October 16, 2026. It presents vibe coding as a spectrum. You start with copy-and-paste prompting in ChatGPT or Gemini, move on to iterative prompting and debugging, and then to agentic tools like Claude Code and ChatGPT Codex. Further sections cover helping students who vibe code during consultations and the guardrails librarians should keep in mind. Everything is written for people with little or no programming background.
